에나콩콩 F&B 팝업 시음회 웹사이트 (포트폴리오 시연용)

실행 방법
1. 압축파일을 풉니다.
2. index.html 파일을 Chrome 등 브라우저에서 엽니다.
3. '사전등록' 버튼을 누르면 register.html 페이지로 이동합니다.
4. '전체 일정 보기' / '전체 프로그램 보기' 버튼을 누르면 팝업이 열립니다.

파일 구조
index.html             메인 행사 안내 페이지
register.html          사전등록 시연 페이지
css/style.css          전체 스타일과 반응형 디자인
js/main.js             모바일 메뉴, 팝업, 폼 시연 동작
assets/*.webp          업로드된 실제 이미지의 로컬 사본 (외부 이미지 URL 없음)

중요: 행사 날짜·장소·프로그램은 가상 예시입니다.
사전등록은 브라우저에서만 완료 화면을 보여주는 데모이며 서버에 접수되지 않습니다.
실제 행사에 사용하려면 확정 일정/장소/운영 정책을 수정하고 서버, 개인정보 처리 절차 등을 추가하세요.
